## What VisionClaw Does

VisionClaw is a full production SaaS platform where each user (tenant) gets their own isolated AI workspace with:

- **14 autonomous AI personas** — each with distinct roles, personalities, and specializations (CEO, CTO, CMO, security analyst, health coach, and more)
- **Deep Research engine** — inspired by Andrej Karpathy's approach, it runs autonomous research experiments, scores results, and iterates without human intervention
- **Multi-tenant isolation** — every user gets their own Stripe payments, Coinbase crypto, WhatsApp approval channel, and email inbox, completely separated from each other
- **Human-in-the-loop safety** — high-risk AI actions (sending emails, executing commands, delegating tasks) require approval via WhatsApp before executing
- **Virtual browser** — agents can browse the web, take screenshots, and interact with pages autonomously
- **Voice synthesis** — ElevenLabs TTS integration for AI persona responses
- **Full payment stack** — Stripe + Coinbase Commerce, each tenant brings their own keys

## The Technical Stack (All on Replit)

- React + TypeScript frontend with Tailwind CSS and shadcn/ui
- Express.js backend with PostgreSQL (Replit DB)
- Google Drive integration for file management
- WhatsApp Business API (Baileys) for mobile approvals
- AgentMail for per-tenant email
- Stripe Connect + BYOK for per-tenant payments
- Coinbase Commerce with per-tenant API keys
- OpenAI, Anthropic, Google Gemini, Grok — multi-provider AI
