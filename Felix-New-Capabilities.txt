PART 6: AUDIENCE Q&A PREPARATION
================================================================================

Q: "How do you handle hallucination?"
A: Three layers: (1) Auto-QA by Proof scores every output, (2) governance rules block
   dangerous actions, (3) human-in-the-loop approval gates for high-risk operations.

Q: "What's the cost per interaction?"
A: Most calls are $0 via OAuth subscription routing (ChatGPT Plus, Gemini). Fallback
   models cost $0.001-0.01 per call via OpenRouter. We've optimized from $600+ in
   learning to near-zero marginal cost for most operations.

Q: "How do you prevent agents from going rogue?"
A: 40 governance rules, trust scores (9 categories per agent), earned autonomy
   progression, admin PIN for sensitive operations, emergency kill switch. Standards
   based on NIST, OWASP, and Singapore IMDA frameworks.

Q: "Is this open source?"
A: The codebase is on GitHub (github.com/Huskyauto/VisionClaw-Agent). Built by AI
   Buddy LLC. The platform itself is a commercial product with free trial access.

Q: "How does the memory system work?"
A: Three tiers: episodic (what happened), semantic (what it means), procedural (how
   to do things). All vectorized with text-embedding-3-small for semantic search.
   DreamTask consolidation runs every 6 hours. LLM-judged relevance picks the most
   useful context in real-time.

Q: "What's the autoresearch system?"
A: Inspired by Karpathy's autoresearch concept. 11 programs run on schedule. Each
   spawns experiments, scores findings 1-10, and auto-injects knowledge scoring 6+
   into the vector knowledge base. The system literally gets smarter while you sleep.

Q: "How did you build this?"
A: One person, with AI assistance, on Replit. 146 TypeScript files, 67 tables,
   ~66,000 lines. The AI agents helped build themselves — Forge writes code, Proof
   reviews it, the research system discovers new patterns that become features.
