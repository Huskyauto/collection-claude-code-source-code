============================================================
Claude Code-Inspired Features (New — March/April 2026)
============================================================

Six major features inspired by Claude Code's agentic architecture, all completed:

--- 1. DreamTask Memory Consolidation Engine ---

Background 'sleep' engine running every 6 hours when idle. Reviews session memories, merges duplicates, archives stale entries, promotes important findings, creates cross-topic summaries. Keeps the knowledge base clean and efficient without human intervention.

--- 2. Adversarial Verification Agent (Auto-QA / De-Sloppify) ---

After every delegation, Proof (persona 8) automatically reviews output quality. Scores completeness, accuracy, clarity, professionalism (1-10). Color-coded verdict badges in live feed. Non-blocking — never delays delegation returns.

--- 3. Agent Live Status Summaries ---

Real-time SSE delegation event feed with animated bubbles, agent icons, depth indicators, timestamps, and per-task cost tracking. Voice narration speaks activity in plain English via Chrome speech synthesis (free). Fully tenant-isolated.

--- 4. Skillify — Session-to-Skill Extraction ---

Extracts reusable execution patterns from successful multi-tool tasks. Stored as 'instincts' with confidence scores. After 3+ observations above 70%, instincts graduate to permanent knowledge in system prompts. Agents improve through experience.

--- 5. Enhanced Stuck Detection and Diagnostics ---

Multi-signal analysis: long-running ops, repetitive loops, consecutive failures. Auto-diagnostic with remediation suggestions. Tenant-safe metadata stripping prevents cross-tenant leakage.

--- 6. LLM-Judged Memory Relevance Scoring ---

GPT-4.1 Mini selects best 5-7 knowledge entries via fast side-query (2s timeout, 30s cache). Smart filtering skips generic docs for active tools, preserves warnings. Vector similarity fallback. Agents always get the most relevant knowledge.
